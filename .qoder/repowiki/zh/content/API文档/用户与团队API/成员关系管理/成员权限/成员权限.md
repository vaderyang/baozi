## 简介
本文档详细描述了通过`userMemberships.ts`实现的成员权限管理功能。系统通过`UserMembership`模型管理用户对文档和集合的访问权限，支持三种权限级别：查看者（viewer）、编辑者（editor）和管理员（admin）。文档详细说明了权限变更API端点的请求参数和响应格式，结合`UserMembership`模型解释了`permission`字段的数据结构和继承机制。同时，文档还描述了权限校验流程、权限提升/降级操作和权限冲突解决策略，并提供了权限与角色关联、批量权限更新和权限审计日志的实现细节。

## 权限级别定义
系统定义了三种主要的权限级别，分别对应不同的操作能力：

- **查看者 (viewer)**: 拥有只读权限，可以查看文档内容但不能进行编辑。
- **编辑者 (editor)**: 拥有读写权限，可以查看和编辑文档内容。
- **管理员 (admin)**: 拥有管理权限，除了读写权限外，还可以管理文档的权限设置。

这些权限级别在`shared/types.ts`中通过`DocumentPermission`枚举定义：

```typescript
export enum DocumentPermission {
  Read = "read",
  ReadWrite = "read_write",
  Admin = "admin",
}
```

## UserMembership模型与数据结构
`UserMembership`模型是权限管理的核心，它定义了用户与文档或集合之间的权限关系。

### 主要字段
- **permission**: 权限级别，类型为`DocumentPermission`或`CollectionPermission`。
- **index**: 排序索引，用于在用户界面中排序。
- **documentId**: 关联的文档ID。
- **collectionId**: 关联的集合ID。
- **userId**: 被授予权限的用户ID。
- **createdById**: 创建此权限的用户ID。
- **sourceId**: 指向根权限的ID，用于权限继承。

### 数据结构示例
```json
{
  "id": "uuid",
  "permission": "read_write",
  "index": "a1",
  "documentId": "uuid",
  "userId": "uuid",
  "createdById": "uuid",
  "sourceId": null,
  "createdAt": "2023-01-01T00:00:00.000Z",
  "updatedAt": "2023-01-01T00:00:00.000Z"
}
```

## 权限继承机制
权限继承机制允许权限从父文档或集合自动传递给子文档，确保权限的一致性。

### 继承原理
当一个文档被共享时，系统会自动为该文档的所有已发布子文档创建相应的`UserMembership`记录。这些记录的`sourceId`指向根权限记录，形成继承链。

### 继承实现
在`UserMembership`模型的`@AfterCreate`钩子中，系统会调用`recreateSourcedMemberships`方法来为所有子文档创建继承的权限：

```typescript
@AfterCreate
static async createSourcedMemberships(
  model: UserMembership,
  options: SaveOptions<UserMembership>
) {
  if (model.sourceId || !model.documentId) {
    return;
  }
  return this.recreateSourcedMemberships(model, options);
}
```

## 权限校验流程
系统通过CanCan授权框架实现权限校验，确保用户只能执行其权限范围内的操作。

### 校验规则
- **更新权限**: 用户必须是权限的所有者或团队管理员。
- **删除权限**: 用户必须是权限的所有者或团队管理员。

### 校验实现
在`server/policies/userMembership.ts`中定义了权限校验规则：

```typescript
allow(User, ["update", "delete"], UserMembership, (actor, membership) =>
  or(
    isOwner(actor, membership),
    actor.isAdmin
  )
);
```

## 权限提升与降级操作
系统支持通过更新`permission`字段来提升或降级用户的权限。

### 操作流程
1. 用户发起权限变更请求。
2. 系统验证请求者的权限。
3. 更新`UserMembership`记录的`permission`字段。
4. 触发`@AfterUpdate`钩子，同步更新所有继承的权限。

### 权限变更同步
当根权限的`permission`字段发生变化时，系统会自动更新所有继承的权限：

```typescript
@AfterUpdate
static async updateSourcedMemberships(
  model: UserMembership,
  options: SaveOptions<UserMembership>
) {
  if (model.sourceId || !model.documentId) {
    return;
  }

  const { transaction } = options;

  if (model.changed("permission")) {
    await this.update(
      {
        permission: model.permission,
      },
      {
        where: {
          userId: model.userId,
          sourceId: model.id,
        },
        transaction,
      }
    );
  }
}
```

## 权限冲突解决策略
系统通过严格的权限校验和事务处理来解决权限冲突。

### 最后管理员保护
为防止团队失去管理员，系统在删除或降级管理员权限时进行特殊检查：

```typescript
private static async validateLastAdminPermission(
  model: UserMembership,
  { transaction }: APIContext["context"]
) {
  const [userMemberships, groupMemberships] = await Promise.all([
    this.count({
      where: {
        collectionId: model.collectionId,
        permission: CollectionPermission.Admin,
      },
      transaction,
    }),
    GroupMembership.count({
      where: {
        collectionId: model.collectionId,
        permission: CollectionPermission.Admin,
      },
      transaction,
    }),
  ]);

  if (userMemberships === 1 && groupMemberships === 0) {
    throw ValidationError(
      "At least one user or group must have manage permissions"
    );
  }
}
```

## 批量权限更新
系统支持通过`copy`静态方法实现批量权限更新。

### 批量更新实现
```typescript
public static async copy(
  where: WhereOptions<UserMembership>,
  document: Document,
  options: SaveOptions
) {
  const { transaction } = options;
  const userMemberships = await this.findAll({
    where,
    transaction,
  });
  await Promise.all(
    userMemberships.map((membership) =>
      this.create(
        {
          documentId: document.id,
          userId: membership.userId,
          sourceId: membership.sourceId ?? membership.id,
          permission: membership.permission,
          createdById: membership.createdById,
        },
        { transaction, hooks: false }
      )
    )
  );
}
```

## 实际使用示例
以下是一个实际使用权限管理功能的示例：

### 共享文档给用户
```javascript
// 创建用户成员权限
const res = await client.post("/documents.add_user", {
  id: documentId,
  userId: targetUserId,
  permission: "read_write",
});

// 响应包含新创建的成员权限
const newMembership = res.data.memberships[0];
```

### 更新用户权限
```javascript
// 更新成员权限的排序索引
await client.post("/userMemberships.update", {
  id: membershipId,
  index: "b1",
});
```

### 获取用户的共享文档列表
```javascript
// 获取当前用户的成员权限列表
const res = await client.post("/userMemberships.list", {
  limit: 20,
  offset: 0,
});

// 响应包含成员权限和相关文档
const { memberships, documents } = res.data;
```
