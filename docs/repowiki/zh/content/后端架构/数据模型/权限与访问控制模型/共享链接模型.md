## 简介
共享链接模型是系统权限体系中的核心组件，它实现了对外部访问的细粒度控制。该模型允许用户通过生成唯一的共享链接，将文档或集合安全地分享给外部用户，同时保持对访问权限的完全控制。共享链接不仅支持基本的查看权限，还提供了丰富的配置选项，包括搜索引擎索引控制、最后更新时间显示、目录显示等。本文档将深入分析共享链接的数据模型、创建流程、访问控制机制以及安全防护措施。

## 访问控制与权限系统
共享链接的访问控制机制确保只有授权用户才能访问共享资源。系统通过多层验证来保护共享内容的安全性。

```mermaid
flowchart TD
Start([请求共享链接]) --> ValidateId["验证ID格式"]
ValidateId --> IsUUID{"是UUID?"}
IsUUID --> |是| LoadByUUID["通过ID加载共享"]
IsUUID --> |否| LoadBySlug["通过slug加载共享"]
LoadByUUID --> CheckRevoked["检查是否已撤销"]
LoadBySlug --> CheckRevoked
CheckRevoked --> IsRevoked{"已撤销?"}
IsRevoked --> |是| Return404["返回404"]
IsRevoked --> |否| CheckTeam["检查团队状态"]
CheckTeam --> IsSuspended{"团队已暂停?"}
IsSuspended --> |是| Return404
IsSuspended --> |否| CheckSharing["检查共享设置"]
CheckSharing --> IsAllowed{"允许共享?"}
IsAllowed --> |否| Return403["返回403"]
IsAllowed --> |是| LoadContent["加载共享内容"]
LoadContent --> ReturnContent["返回内容"]
```

## 结论
共享链接模型为系统提供了强大而灵活的外部访问控制机制。通过精细的权限管理、完善的安全防护和直观的用户界面，该模型实现了文档和集合的安全共享。系统支持多种配置选项，包括搜索引擎索引控制、最后更新时间显示和目录显示，满足不同场景下的共享需求。未来可以进一步增强链接的时效性控制和访问分析功能，提升用户体验和安全性。
