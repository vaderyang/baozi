## 用户身份验证流程
系统实现了多因素身份验证流程，包括基于JWT的会话管理和基于邮箱的登录验证。用户可以通过邮箱链接或验证码进行身份验证，系统会根据用户状态和团队设置进行相应的安全检查。

```mermaid
sequenceDiagram
participant 用户

participant Redis
用户->>服务器 : 发送登录请求
服务器->>服务器 : 验证用户存在性
服务器->>邮箱服务 : 生成邮箱登录令牌
邮箱服务->>Redis : 存储验证码
Redis-->>邮箱服务 : 存储成功
邮箱服务->>用户 : 发送包含令牌的邮件
用户->>服务器 : 点击邮件中的链接
服务器->>服务器 : 验证令牌有效性
服务器->>服务器 : 检查IP地址匹配
服务器->>服务器 : 更新用户登录状态
服务器-->>用户 : 重定向到应用
```

## JWT令牌管理
系统使用JWT（JSON Web Token）进行用户会话管理，实现了多种类型的令牌以满足不同的安全需求。

### JWT令牌类型
系统实现了多种JWT令牌类型，每种类型都有特定的用途和安全特性：

| 令牌类型 | 用途 | 过期时间 | 安全特性 |
|--------|------|--------|--------|
| 会话令牌 | API请求认证 | 可配置 | 基于jwtSecret签名 |
| 协作令牌 | 实时协作 | 24小时 | 基于jwtSecret签名 |
| 转移令牌 | 子域名会话转移 | 1分钟 | 一次性使用，带创建时间戳 |
| 邮箱登录令牌 | 邮箱登录验证 | 10分钟 | 绑定IP地址，带创建时间戳 |

### 令牌生成与验证
系统通过`getJwtToken`方法生成会话令牌，使用用户的`jwtSecret`作为签名密钥。令牌包含用户ID、过期时间和令牌类型等信息。

```mermaid
flowchart TD
Start([生成JWT令牌]) --> CheckUser["验证用户存在性"]
CheckUser --> GeneratePayload["构建令牌负载"]
GeneratePayload --> SetClaims["设置声明: id, expiresAt, type"]
SetClaims --> SignToken["使用jwtSecret签名"]
SignToken --> ReturnToken["返回JWT令牌"]
ReturnToken --> End([完成])
```

系统实现了安全的邮箱验证和密码重置机制，使用双重验证方式确保账户安全。

## 会话管理与安全
系统实现了全面的会话管理机制，包括会话固定攻击防护、令牌轮换和会话转移等功能。

### jwtSecret加密存储
用户的`jwtSecret`字段使用`@Encrypted`装饰器进行加密存储，确保密钥在数据库中的安全性。

```mermaid
flowchart TD

StoreDB --> End([完成])
Login([用户登录]) --> RetrieveSecret["从数据库获取加密密钥"]
RetrieveSecret --> DecryptSecret["解密密钥"]
DecryptSecret --> SignToken["使用密钥签名JWT"]
SignToken --> End2([返回令牌])
```

## 安全最佳实践
基于系统实现，总结以下安全最佳实践：

### 密码策略
- 使用强随机数生成器创建jwtSecret（64字节十六进制字符串）
- 对敏感字段（如jwtSecret）进行加密存储
- 定期轮换JWT密钥以减少密钥泄露风险

### 登录尝试限制
- 使用速率限制中间件（RateLimiter）防止暴力破解
- 每小时限制10次邮箱登录请求
- 每分钟限制5次回调请求

### 可疑活动检测
- 绑定邮箱登录令牌到用户IP地址
- 验证令牌创建时间，防止重放攻击
- 记录用户登录IP和时间，便于审计

### 双因素认证流程
系统通过邮箱验证码实现类似双因素认证的安全机制：
1. 用户请求登录
2. 系统生成6位数字验证码并发送到注册邮箱
3. 用户输入收到的验证码
4. 系统验证验证码的正确性和时效性
5. 验证成功后创建会话

```mermaid
flowchart TD
A([用户请求登录]) --> B{选择验证方式}
B --> |链接| C[生成邮箱登录令牌]
B --> |验证码| D[生成6位数字验证码]
C --> E[发送包含令牌的邮件]
D --> F[发送包含验证码的邮件]
E --> G[用户点击链接]
F --> H[用户输入验证码]
G --> I[验证令牌和IP]
H --> J[验证验证码]
I --> K[创建会话]
J --> K
K --> L[重定向到应用]
```
